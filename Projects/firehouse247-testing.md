# Firehouse 24*7 Testing Documentation

Website: https://www.firehouse247.com

## Project Overview
Firehouse 24*7 is a platform designed to manage emergency fire services, incident reporting, and station management.

## Testing Responsibilities
- Designed and executed manual test cases
- Performed functional and regression testing
- Verified API responses
- Logged and tracked bugs using JIRA
- Conducted UI validation across browsers

## Testing Types
- Functional Testing
- Regression Testing
- API Testing
- UI Testing

## Tools Used
- JIRA
- Postman
- Chrome DevTools
