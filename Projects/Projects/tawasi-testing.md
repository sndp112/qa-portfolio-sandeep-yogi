# Tawasi Testing Documentation

## Project Overview
Tawasi is a food ordering platform similar to Zomato designed for Palestine County. It allows restaurants to list menus and provides company-specific order codes for discounts.

## Testing Responsibilities
- Performed functional testing of ordering workflow
- Verified discount code functionality
- Tested restaurant listing and search features
- Validated payment and order confirmation flows
- Logged and tracked bugs in JIRA

## Testing Types
- Functional Testing
- Regression Testing
- UI Testing
- User Acceptance Testing

## Tools Used
- JIRA
- Chrome DevTools
