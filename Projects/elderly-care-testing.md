# Elderly Care Pro Testing Documentation

## Project Overview
Elderly Care Pro is a mobile application designed to provide healthcare services and support for elderly users.

## Testing Responsibilities
- Tested user onboarding flow
- Verified service booking functionality
- Validated notifications and reminders
- Checked UI accessibility for elderly users

## Testing Types
- Mobile Testing
- Functional Testing
- UI Testing
- Usability Testing

## Tools Used
- JIRA
- Android Studio Emulator
