# Lurnigo Testing Documentation

## Project Overview
Lurnigo is an online learning platform that provides access to live classes and recorded educational content.

## Testing Responsibilities
- Tested user registration and login modules
- Verified course access and playback functionality
- Validated live class joining flow
- Checked recorded content streaming
- Identified usability issues

## Testing Types
- Functional Testing
- Regression Testing
- UI Testing
- Usability Testing

## Tools Used
- JIRA
- Chrome DevTools
