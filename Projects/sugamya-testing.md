# Sugamya Testing Documentation

## Project Overview
Sugamya is a healthcare platform providing Ayurveda prescriptions with separate panels for doctors, customers, and tele-counselors.

## Testing Responsibilities
- Tested doctor panel for prescription management
- Verified customer appointment booking flow
- Validated tele-counselor interactions
- Checked data validation and form submissions
- Performed cross-browser testing

## Testing Types
- Functional Testing
- Integration Testing
- Regression Testing
- UAT Testing

## Tools Used
- JIRA
- Postman
- Chrome DevTools
